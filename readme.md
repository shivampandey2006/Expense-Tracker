# Expense Tracker

A simple console-based expense tracker built using C++.

## Features

- Add expenses with name, category, and amount
- Display all recorded expenses
- Calculate total expenditure
- Find the highest expense
- Handle multiple expenses with the same highest amount  

## Concepts Used

- C++ Vectors
- Strings
- Loops
- Conditional Statements
- `getline()`
- `stod()`
- Basic input/output

## Menu
1. Add Expenses
2. Display All The Expenses
3. Calculate Total Expenditure
4. Find Highest Expenses
5. Exit

## How to Run

1) Compile the program using:
g++ Expense_Tracker.cpp -o Expense_Tracker

2) After successful compilation, run the program using:
.\Expense_Tracker.exe
